# Салон красоты — система записи клиентов

![CI](https://github.com/alya-azov/beauty_salon_project/actions/workflows/ci.yml/badge.svg)

Консольное приложение для салона красоты на Python. Клиенты регистрируются, смотрят каталог
услуг и мастеров и записываются на свободное время. Администратор ведёт услуги, мастеров,
их расписание и все записи. Данные хранятся в PostgreSQL, работа с базой построена на SQLAlchemy ORM.

## Возможности

**Для клиента**
- регистрация и вход по номеру телефона и паролю;
- просмотр и изменение личных данных, смена пароля, удаление аккаунта;
- каталог услуг по категориям и мастеров по специальностям;
- запись на услугу: после выбора услуги и даты приложение показывает только тех мастеров,
  которые выполняют эту услугу и свободны в этот день, а затем их свободные слоты;
- просмотр предстоящих и прошедших записей, отмена записи.

**Для администратора**
- управление клиентами: поиск, редактирование, начисление покупок, удаление;
- управление мастерами и их специализацией по категориям услуг;
- управление услугами и категориями;
- расписание мастеров: рабочие дни, перерывы, массовое заполнение расписания на период
  по выбранным дням недели;
- управление записями и их статусами: запланирована, выполнена, отменена, неявка.

## Логика записи

Свободные слоты строятся по рабочему дню мастера с шагом 30 минут. Слот считается свободным,
если услуга целиком помещается в рабочее время и не пересекается с перерывами и другими записями.
При создании записи все условия проверяются повторно: мастер выполняет услуги этой категории,
день не выходной, время не занято.

## Карта лояльности

Каждый клиент при регистрации получает карту салона. Уровень карты растёт вместе с суммой
покупок и даёт скидку на следующие:

| Уровень  | Сумма покупок | Скидка |
|----------|---------------|--------|
| STANDARD | до 5 000 ₽    | 0 %    |
| SILVER   | от 5 000 ₽    | 3 %    |
| GOLD     | от 15 000 ₽   | 7 %    |
| PLATINUM | от 30 000 ₽   | 10 %   |

## Архитектура

Код разделён на слои:

```
models/            ORM-модели: клиенты и карты лояльности, мастера, услуги, расписание, записи
management/        бизнес-логика: сервисные классы для работы с базой
user_interface/    консольный ввод и вывод
auth/              вход клиентов и администратора, хэширование паролей
main.py            точка входа и меню
tests/             тесты на pytest
docs/              документация на Sphinx
```

Схема базы данных:

```
clients ──1:1── salon_cards
clients ──1:N── appointments ──N:1── services ──N:1── service_categories
masters ──1:N── master_schedule ──1:N── master_breaks
masters ──1:N── appointments
masters ──N:M── service_categories
```

## Тестирование и CI

Бизнес-логика покрыта тестами на pytest (25 тестов), которые работают на SQLite в памяти.
При каждом push GitHub Actions запускает тесты, проверку типов mypy и сборку документации Sphinx.

## Стек

Python 3.12 · SQLAlchemy · PostgreSQL · pytest · mypy · Sphinx · GitHub Actions
